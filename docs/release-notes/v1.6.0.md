### Required vs optional entities
- **Required** now: the burner / heat-demand entity, at least one **indoor temperature** sensor, and an **outdoor temperature source** — an outdoor sensor **or** a weather entity. The form will not save without them.
- **Weather as outdoor source**: if no outdoor sensor is set, the weather entity's current temperature is used as the outdoor temperature (balance point, degree-days, heating curve, comfort verdict all work with it). If both are set, the outdoor sensor wins.
- Everything else (flame, flow, return, setpoint, thermoregulation, thermostat, pressure, season) stays optional. Leave one empty and the entities and card sections that depend on it are simply not created.
- README: new table of what each optional sensor enables.

### Upgrade
Update via HACS and restart Home Assistant. Existing entries keep working; ⋮ → **Reconfigure** asks for the required fields the next time you open it. Ctrl+F5 in the browser.
