### Fixed
- **Heating rate disappeared after a restart or an update**: the last measured room warming rate (°C/h) was kept only in memory, so it showed as unknown until the next check, 45 minutes after the next burner start. It is now saved and restored; for older stores it is taken from the last checked cycle
- **Cycles at exactly 0 °C** (outdoor, off time, …) lost that value in the store since 1.8.0, because zero values were left out to save space. Zeros are now dropped only from the hourly counters, where they are restored on load

### Upgrade
Update via HACS and restart Home Assistant. Stored statistics are kept.
