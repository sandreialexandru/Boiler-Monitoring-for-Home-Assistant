### New: detailed tooltips (mouse and touch)
Hover any bar, dot or timeline segment, or **tap** it on a phone or wall tablet:
- **Last 24 hours**: start – end time, burn duration, short-cycle flag
- **Last 14 days / Burn vs outdoor**: day, burn time, cycles (and short ones), outdoor average, condensing %, average ΔT
- **Heating curve**: day and hour, outdoor, target flow, actual flow, actual − target, regulation mode

Dots have a larger touch area, so they are easy to hit with a finger.

### Docs
The README now has a full plain-language guide: what every value and chart means, how the curve slope and degree-days are calculated (and why 18 °C), how to read each chart, and a step-by-step method for tuning the heating curve.

### Upgrade
Update via HACS, restart Home Assistant, then hard-refresh the browser (Ctrl+F5).
