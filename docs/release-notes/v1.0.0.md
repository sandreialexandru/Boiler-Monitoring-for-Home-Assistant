First release of **Boiler Monitor**, an advanced boiler monitoring integration for Home Assistant with its own Lovelace card.

![Full card](https://raw.githubusercontent.com/sandreialexandru/Boiler-Monitoring-for-Home-Assistant/v1.0.0/docs/images/card-full-light.png)

### Highlights
- **Cycle statistics**: cycles today/per hour, average burn & off time, duty cycle, burn time today
- **Restart-safe short-cycling detection**: off-time is measured from the stored stop time, so a Home Assistant restart never produces a false alarm. Relay glitches are filtered out
- **Condensing efficiency**: % of burn time with the return below the threshold, plus a *Condensation lost* alert
- **Flow/return ΔT** and a **heating-effect** check (°C/h in the rooms)
- **Outdoor correlation**: regression of daily burn hours vs outdoor temperature, **balance point**, **burn hours per degree-day**
- **Any burner source**: `switch`, `binary_sensor`, `input_boolean`, `climate` (`hvac_action`) or a text sensor
- **Heating-season gating**, problem binary sensors, events, tagged push notifications, CSV log
- **Lovelace card** in full and compact modes, registered automatically (no resource to add), with a visual editor and light/dark theme support
- UI-only setup (config, options and reconfigure flows), English & Romanian translations

### Install
HACS → Integrations → ⋮ → Custom repositories → add this repo as **Integration** → install **Boiler Monitor** → restart.
Manual: extract `boiler_monitor.zip` into `/config/custom_components/` and restart.

Then: **Settings → Devices & services → Add integration → Boiler Monitor**.

See the [README](https://github.com/sandreialexandru/Boiler-Monitoring-for-Home-Assistant#readme) for the full documentation and the card configuration.
