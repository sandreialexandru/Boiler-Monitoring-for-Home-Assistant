### Fixed: card sometimes missing ("Custom element doesn't exist"), especially in the companion app
Until now the card was injected only into the page Home Assistant serves when the frontend first loads. The companion app (and browsers) keep that page cached, so when the cached copy was older than the integration's registration, or after the cache expired at the wrong moment, the card's script was never loaded.

The integration now also adds the card as a **dashboard resource** (Settings → Dashboards → ⋮ → Resources), which every dashboard fetches each time it opens:
- added automatically after Home Assistant starts
- the URL carries the version (`?v=1.1.3`) and is updated on every upgrade, so old cached copies are never used
- duplicates are cleaned up; the resource is removed when you delete the last boiler
- YAML-mode dashboards: resources are read-only there; see the README FAQ for the 3-line snippet

### Upgrade
Update via HACS and restart Home Assistant. Then, **once**:
- browser: Ctrl+F5
- companion app: Settings → Companion app → Debugging → **Reset frontend cache**
