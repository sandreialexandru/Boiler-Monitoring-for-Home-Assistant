### New: flow target vs actual, regulation mode and heating curve
Three new optional entities (⋮ → **Reconfigure**):
- **Flow target / setpoint sensor**, e.g. Ariston *CH flow setpoint temp*
- **Automatic thermoregulation entity**, e.g. Ariston *automatic thermoregulation*
- **Heating circuit pressure sensor**, e.g. Ariston *heating circuit pressure*

What you get:
- `sensor.<name>_regulation_mode`: *weather compensation* or *fixed flow*
- `sensor.<name>_flow_vs_target_24h`: average real flow − target while burning (warm-up ignored)
- `sensor.<name>_heating_curve_slope`: the real slope of the curve, fitted from the last 7 days
- **Card:** a "Target" tile with the mode, and a new chart that adapts to the mode:
  - *Weather compensation*: target vs outdoor (hourly), real flow, the fitted curve, slope, target at 0 °C and −10 °C
  - *Fixed flow*: the fixed flow line and the real flow while burning
- CSV log: `MODE` when thermoregulation is switched, `SETPOINT` when the fixed flow temperature is changed. Event `boiler_monitor_regulation_changed`.

### New: pressure
- Pressure tile on the card (red when out of range, ↓/↑ trend arrow)
- `binary_sensor.<name>_pressure_problem` with push alert, event `boiler_monitor_pressure_problem`
- `sensor.<name>_pressure_change_7d` for slow-leak detection
- Options: minimum / maximum pressure (default 1.0 / 2.5 bar). Pressure is monitored all year.

### Upgrade
Update via HACS and restart. Then go to **Settings → Devices & services → Boiler Monitor → ⋮ → Reconfigure** to pick the new entities, and hard-refresh the browser (Ctrl+F5).
