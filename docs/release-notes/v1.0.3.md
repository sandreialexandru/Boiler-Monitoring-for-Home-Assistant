### Fixed
- **Condensing ratio:** a return temperature exactly equal to the threshold now counts as condensing. Before, a return sitting at e.g. 45.0 °C with a 45 °C threshold lowered the ratio below 100 %.

### New
- `sensor.<name>_condensing_ratio_24h` has diagnostic attributes so you can see how the ratio was calculated:
  - `return_threshold`: the threshold in use
  - `condensing_minutes_24h`: sampled burning minutes with return ≤ threshold
  - `burning_minutes_sampled_24h`: all sampled burning minutes
  - `return_max_while_burning_24h`: highest return temperature seen while burning

### Note
The ratio covers the last 24 hours. Each minute is judged against the threshold that was set **at that minute**, so after changing the threshold the ratio needs up to 24 h to fully reflect the new value. Run `boiler_monitor.reset_statistics` to start over immediately.

### Upgrade
Update via HACS and restart Home Assistant.
