### Fixed: "Heating ineffective" while the boiler is not running
- The alert is now raised only if the burner ran at least half of the check period. A short burn in mild weather, after which the rooms do not rise, is no longer judged
- If a room thermostat is set and the rooms are already at or above its target, the check is skipped
- The alert clears by itself once the burner has been off for a whole check period (45 minutes by default). Before, it stayed on until the next burn, which in warm weather could be days

### Upgrade
Update via HACS and restart Home Assistant. Stored statistics are kept. Ctrl+F5 in the browser to load the new card version.
