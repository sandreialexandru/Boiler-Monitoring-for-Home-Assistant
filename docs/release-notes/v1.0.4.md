### Changed
- **Card:** durations are no longer shown as decimal hours. Everything is now in hours and minutes:
  - burn today, average burn, average off: `2 h 14 min`, `16 min`
  - "burning for …" in the header: `1 h 05 min`
  - daily bars: `5h48` (the labels hide automatically on narrow cards; hover a bar for the full value)
  - burn per degree-day: shown in **minutes** per degree-day
- README screenshots updated.

The sensors themselves are unchanged (same units), so history and automations are not affected.

### Upgrade
Update via HACS, restart Home Assistant, then hard-refresh the browser (Ctrl+F5) to load the new card.
